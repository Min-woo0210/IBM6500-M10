# M10 Quarto Portfolio

## Before publishing

1. Replace `profile-placeholder.svg` with a professional photo named `profile.jpg`.
2. Update the image name in `index.qmd`.
3. Replace every `YOUR-USERNAME`, `YOUR-PROFILE`, and bracketed placeholder.
4. Update the GitHub URL in `_quarto.yml`.
5. Install Quarto, then run `quarto preview` to inspect the site.
6. Render the final HTML with `quarto render`.

## GitHub Pages

Create a GitHub repository, push this folder, and enable GitHub Pages from the `gh-pages` branch or GitHub Actions. The final submission should include:

- Website: `https://min-woo0210.github.io/IBM6500-M10/`
- Repository: `https://github.com/Min-woo0210/IBM6500-M10`
