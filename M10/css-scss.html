Extending a Quarto Website with CSS / SCSS

Why Custom Styling Matters

CSS/SCSS makes it possible to create a consistent visual identity and improve hierarchy, readability, accessibility, and brand alignment.

How This Website Uses CSS

The stylesheet is connected in _quarto.yml with css: styles.css. This project uses navy for professionalism, coral for emphasis, whitespace for readability, and cards to group information.

CSS and SCSS

CSS is the browser-ready language that controls presentation. SCSS is a preprocessor language that adds variables, nesting, and reusable mixins. SCSS is compiled into CSS that browsers can read.

What I Learned

Custom CSS is most effective when it supports the audience and the content.
